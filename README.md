# 香港教師操守 · 資料站

以《教師專業操守指引》與教育局提交立法會文件為骨幹的完整整理：準則、處分、個案數據、流程與查核。
純靜態網頁，零外部依賴，可直接以 GitHub Pages 發佈。

## 內容

- **制度定位** — 法例層（《教育條例》第 42／47／52 條）／指引層／程序層／培訓層四層拆解
- **八項準則** — 專業信念、恪守法治、以身作則、廉潔公正、盡忠職守、關愛學生、尊重私隱、維護專業
- **個案數據** — 2023–2025 年按處分級別的表列（取消註冊 47／71／37）＋ 兩張柱圖
- **處分階梯** — 口頭提示 → 書面勸喻 → 書面警告 → 譴責信 → 取消註冊，附 2025 年各級數字
- **處理流程** — 由發現投訴到登記冊更新的六步
- **聘用查核** — 通告 14/2023、向局方查核、前僱主證明、離職一年以上申報、每三年刑事查核
- **培訓** — 職前課程框架、核心培訓、「T-標準」、150 小時中的 30 小時
- **爭議地帶** — 社交媒體、政治表態、師生界線、AI 代筆、收受利益、投訴文化
- **12 條常見問題**、**方法限制**、**10 項資料來源**

## 技術

- `index.html` — 內容與結構（語意化 HTML，無框架）
- `assets/style.css` — 設計系統（米紙 + 硃紅印章色，準則卡片、階梯、流程線）
- `assets/app.js` — 閱讀進度、導覽 scroll spy、階梯數字漸現

無 CDN、無建置步驟、無追蹤碼。

## 重要說明

《指引》是行政指引，《教育條例》才是法律依據；違反指引不等於犯法，但可能導致紀律行動。
本頁「應該／不應」為實務重點整理，非指引原文；個別判斷須以原文及條例為準。本頁非法律意見。
